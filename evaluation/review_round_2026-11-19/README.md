# 本轮复核的读法

入口是 [summary.md](summary.md)，逐篇证据与全部输出见 [detailed_review.md](detailed_review.md)。本轮覆盖 24 篇、7 条件、168 条输出，不覆盖更早的校准集。

这是尚未裁决的工作复核，来源字段暂不填写。未更改既有来源记录、空白人工表、冻结参考或原评分，也未生成假定已完成独立评审的记录。已有汇总结论在本轮开始前可见，因此不宣称盲法独立性，不计算评审者一致性。本轮记录不得被自动当作最终裁决或已完成的人工验证。

## 采用的评分边界

- 按 `data_package/docs/annotation_guide.md` 3.0、`evaluation/rating_protocol.md` 与 `evaluation/metric_definitions.md` 阅读原句和完整摘要。只判断给定来源支持到什么程度，不推断临床或科学真伪。
- 机构、发表日期、归属、别名不作为科学内容错误。数量、物种、性别、干预、比较对象、结局、方向及不确定性属于科学内容。科学数量在摘要缺失时，不以猜测或静默删除认证成功修复。
- q1 评价残留夸大及来源无法确认的断言。q3 评价相对草稿新引入且无来源支持的科学信息；原句已有的未支持断言留在 q1，避免一律当作新增。新写的错误元评论也在 q3 记录。
- q2 评价已支持内容的丢失、弱化或改变。删除原本不受支持的内容本身不算 q2 错误；不能判定是否受到支持时记 uncertain。具体研究结果被改成潜在结果、明确物种限制被移除、已支持研究背景被删除，均记录相应理由。
- q4：S1/S3 为 yes，S2 为 no；S4 和 UNRESOLVED 为 uncertain，因为不能确认原句全部科学内容或评分边界。q4 不用于认证修复。纯拒答的 q1–q3、q5 为 not_applicable，仍填写 q4 及证据充分性，依照 evaluation/rating_protocol.md；已有 Excel 构建说明中“拒答五问全不适用”的不同约定未用于本轮。
- q5 按可独立使用的替换声明判断。单独返回 `leads to...` 等片段、原句后附冲突的 ABSTAIN，不作为干净可读的替换文本。原始格式失败另列，不因文本看似合理而消除。
- 同篇、同动作、同解析状态、完全相同文本合为一组判断，共 126 组，展开后仍为 168 条实际输出。不同条件的证据充分性按实际输入单独评价，相同文本不构成新的独立评审。

## 计数规则

- S1、S3 分开计数，均要求实际 revise、q1/q2/q3=no、q5=yes、原始解析有效。依赖摘要的条件还须有足够实际输入，且输出能由其支持；固定规则 A 不以“没有摘要输入”自动判文本修复失败。
- 所有 S1、S3 拒答及不确定判断留在相应分母。S1 非拒答覆盖率保存在 `stratified_metrics.json`。
- S2 文本严格不同即为误改；有害弱化另由 q2=yes 计算。S2 拒答单列，不记作误改。
- S4 的期望行为是纯拒答。给出部分正确改写不等于核实原句，也不能计为修复。
- 事实保留为非拒答中 q2=no 且 q3=no；不等同于 q1 已通过。原始格式失败仍留在非拒答分母，并另外报告。
- 四篇 UNRESOLVED 保留在全部 24 条输出的分母与不确定计数中，不计为成功。不报告单一总体成功率。
- 检索证据不足与原摘要本身不足分别记录。完整摘要可支持而实际检索片段遗漏的信息，不认证为成功编辑。

## 四个待决边界

1. `PILOT-29-033`：感染准备、附着和持续存留结果能否概括为 virulence。
2. `PILOT-13-11-003-1`：regardless 是声称有机奶比较优势方向仍在，还是声称不受季节和天气影响。
3. `PILOT-25-162`：普通研究摘要省略老年 Medicare 及内科医生限制的可接受程度。该句未明确写全部年龄；与维生素 A 案例主动指定 under five 的年龄范围区别记录。
4. `PILOT-10-11-003-1`：unhealthy 能否作为高脂及高碳水食品的通俗等义概括。

上述边界的变化会影响分层分母。本轮数据属于新参考版本下的敏感性结果，不替换旧版结果。与仓库既有参考的七处类别差异详列在汇总中；没有六份已填 Excel，无法还原此前两个版本的七例分歧。

## 文件及重建

- `reference_reviews.jsonl`：24 条原句、完整摘要、文献标识、来源链接、引句、类别和理由。
- `output_ratings.jsonl`：168 条输出、五问、动作、失败记录、证据充分性及逐条理由。
- `display_group_reviews.jsonl`：126 个文本组与实际输出编号的对应。
- `stratified_metrics.json`：七种条件的分层数量、拒答、覆盖率、事实保留及不确定计数。
- `reference_version_changes.json`：与既有参考的类别差异。
- `manifest.json`：覆盖范围、先前结论暴露、依赖文件散列及核验范围。
- `assessments.json`、`evidence_assessments.json`：本轮原始工作判断，保留供追溯。

在仓库根目录运行 `python evaluation/review_round_2026-11-19/build_review.py` 重建派生文件。构建只依赖 Python 标准库，且只写入本轮目录。未联网重新核验文献身份，身份信息沿用仓库记录；摘要、原始输出和实际证据的散列、引句及编号映射均逐项校验。
