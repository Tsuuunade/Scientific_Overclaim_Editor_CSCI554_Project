# Scientific Overclaim Editor experiments

The current completed study is in [paper_study/](paper_study/README.md). It contains 24 paper-separated cases, seven conditions, 168 outputs, draft source-based assessments, paired analyses, error analysis and figures.

- [Experimental setup](paper_study/EXPERIMENT_SETUP.md)
- [Results](paper_study/RESULTS.md)
- [Error analysis and next priorities](paper_study/ERROR_ANALYSIS.md)
- [Information for the final presentation](paper_study/PRESENTATION_NOTES.md)
- [Independent human-review procedure](paper_study/HUMAN_REVIEW.md)

The new reference categories and semantic scores are automated drafts. Independent human verification remains pending. The experiments support a feasibility study, not a human-validated effectiveness claim.

The original eight-case development outputs remain in `results/runs/`. Their setup and findings are preserved in [paper_study/legacy/](paper_study/legacy/README.md). All original project data and prior result records are retained. Source-recovery code now preserves mathematical comparison signs. Fresh corrected provider responses for the new study are stored under `paper_study/sources/`.

Use the commands in the current study's README to verify and analyze the recorded run. Use its replay command to regenerate outputs in a separate directory. No experiment changes have been pushed to GitHub.
